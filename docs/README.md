# OctoAcme Project Management Process Documentation

Welcome to the OctoAcme project management hub. This directory contains comprehensive guides and best practices for running projects at OctoAcme, from initiation through retrospectives.

## OctoAcme Project Management Overview

OctoAcme follows a structured, iterative approach to project delivery centered on five core principles:

- **Customer-first mindset**: Prioritizing customer value and usability in all decisions
- **Iterative delivery**: Shipping small, testable increments to gather feedback early
- **Clear ownership**: Each project has a named Project Manager (PM) and Product Manager (PdM) responsible for execution and outcomes
- **Data-informed decisions**: Measuring impact and iterating based on evidence, not assumptions
- **Psychological safety**: Encouraging feedback, learning, and continuous improvement across all team levels

## Project Lifecycle

Every OctoAcme project follows five core phases:

1. **Initiation** — Validate business need, align stakeholders, and create a project one-pager
2. **Planning** — Break down work into shippable increments, estimate scope, identify risks and dependencies
3. **Execution** — Build, test, track progress daily, and manage blockers collaboratively
4. **Release** — Deploy to production, verify functionality, and communicate with stakeholders
5. **Close & Retrospective** — Capture learnings, document outcomes, and convert insights into improvements

## Communication Cadence

OctoAcme projects operate on a consistent communication rhythm:

- **Daily standups** — 15-minute team syncs to align on progress, blockers, and dependencies
- **Weekly PM + PdM sync** — Coordination between Project and Product Management
- **Twice-weekly delivery team meetings** — Or more frequently as needed during execution
- **Monthly stakeholder updates** — High-level progress and key decisions
- **Ad-hoc escalations** — For critical blockers, risks, or decisions requiring immediate attention
